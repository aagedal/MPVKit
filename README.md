# Aagedal MPVKit-GPL macOS candidate

This immutable candidate packages mpv 0.41.0 and FFmpeg n8.1.2 with the
attributed IINA CoreAudio device/channel-map correction, GPL, Metal and Samba.
The Swift package exposes macOS 12+ and MPVKit-GPL, with Lua disabled.

See [source and offline rebuild instructions](docs/CoreAudioPublication/README.md)
for the complete source/input release stage and verified build receipts.
This dependency release does not establish downstream app beta acceptance.
